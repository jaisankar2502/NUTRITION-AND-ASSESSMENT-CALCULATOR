# Nutrition & Assessment Calculator

A React + Vite starter app for nutrition assessment with BMI, BMR, TDEE, macro targets, and food intake logging.

## Setup

1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.

## Features

- Profile input: age, sex, weight, height, activity level
- Automatic BMI, BMR, and TDEE calculation
- Macro target breakdown based on percentage ratios
- Food intake log with totals for calories, protein, carbs, and fat

## Notes

This project is a starter implementation. If you want Excel-specific formulas or additional assessment features from your workbook, share the workbook details or upload the project files.
